# Gênero e eleições na América do Sul

Site independente sobre promessas de campanha relativas a gênero nas eleições presidenciais de 2026 no Brasil, na Colômbia e no Peru, com linha do tempo de conquistas e retrocessos, jogos, cards para redes e um roteiro de entrevista testado no CEASA/PE.

Trabalho final de disciplina do PPGCP/UFPE — Vitória Santos, Amanda Simões e Prof. Dr. Diego Freitas Rodrigues.

## Arquivos

- `index.html` — o site inteiro (dados, fotos, traduções PT/ES/EN e o PDF do questionário já estão embutidos).
- `assets/questionario-ceasa.pdf` — cópia do questionário, para quem abrir o link direto.
- `favicon.ico`, `favicon.svg`, `apple-touch-icon.png` — ícone do site na aba do navegador e no celular.
- `.nojekyll` — avisa o GitHub Pages para publicar os arquivos como estão.
